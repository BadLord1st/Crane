# Visual Check Report (Template)

## Overall
- Status: PASS | FAIL | MIXED | INCONCLUSIVE
- Notes: one paragraph summary

## VAC Results
Format:
- VAC-ID: PASS/FAIL/UNKNOWN — evidence

Example:
- VAC-AUTH-001: PASS — (header) "Sign in" is visible at top center
- VAC-AUTH-002: FAIL — password input is not visible; only email field is shown
- VAC-AUTH-003: UNKNOWN — toast area not present in the screenshot

## Follow-ups
Cheapest next checks to resolve FAIL/UNKNOWN items.
